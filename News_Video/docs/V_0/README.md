# V_0 项目手册

本版记录新闻视频项目当前的代码结构、原理、使用与维护方式。版本名称由用户指定；当前执行环境是 Windows 本地 Codex，未来可由 DSH 按说明接手。

## 阅读顺序

- [01｜项目原理与系统架构](01_principles.md)：先理解脚本、AI执行者与平台各自负责什么。
- [02｜项目结构、配置与依赖](02_structure.md)：目录、核心模块、参数和本机运行时。
- [03｜使用手册与常用命令](03_operations.md)：日常操作、生产链、临时新闻及自动任务。
- [04｜内容、语音、画面与投稿规范](04_standards.md)：节目要求和提交状态判定。
- [05｜排错、版本基线与DSH交接](05_maintenance.md)：日志、故障定位、验证边界与迁移。

## 一句话理解

项目先用本地脚本采集、存储和去重，再由当前AI执行者核验与写稿，接着用本地模型配音、HTML生成视频，最后只从release自动投稿并回查公开发布。
